Zone Management System

The system uses a sophisticated zone-based approach to manage positions through their lifecycle:

Zone UPNL Range Actions Transitions
NEUTRAL -15% < UPNL < +15% Monitor position → AVERAGING or PROFIT_TAKING
AVERAGING UPNL ≤ -15% Execute Fibonacci averaging → NEUTRAL or SURPLUS_DUMP
SURPLUS_DUMP UPNL > +15% (after averaging) Two-stage profit taking → NEUTRAL (after Stage 2)
PROFIT_TAKING UPNL > +15% (no averaging) Close position → Position closed
STOP_LOSS UPNL ≤ stop threshold Emergency close → Position closed
Note: After Stage 2 surplus dump completion, positions reset to NEUTRAL zone with averaging_steps = 0, allowing for multiple surplus dump cycles.

Fibonacci Averaging Strategy

The system implements an adaptive Fibonacci-based averaging strategy that adjusts thresholds based on historical price volatility:

Step 1: -42% UPNL → 1.0x size multiplier (21/50 Fibonacci) Step 2: -68% UPNL → 2.0x size multiplier (34/50 Fibonacci) Step 3: -84% UPNL → 3.0x size multiplier (42/50 Fibonacci) Step 4: -94% UPNL → 4.0x size multiplier (47/50 Fibonacci) Step 5: -100% UPNL → 5.0x size multiplier (50/50 Fibonacci)

Surplus Dump Mechanism

When positions recover after averaging, the system implements a two-stage surplus dump to secure profits:

Stage 1 (85% of Peak)

  • Triggers when UPNL drops to 85% of peak
  • Dumps 50% of surplus size
  • Preserves position for further gains

Stage 2 (50% of Peak)

  • Triggers when UPNL drops to 50% of peak
  • Dumps remaining surplus
  • Resets position to original size
  • Returns to NEUTRAL zone
Reset Behavior: After Stage 2 completion, the position resets to its original state with averaging_steps = 0, allowing it to go through another complete cycle if market conditions warrant.
